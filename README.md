# Profitability AI

ХҚТУ хакатоны, NEXTGEN IT WEEK 2026, 01-трек «University AI & Analytics», Кейс 01.

Бұл веб-қосымша ұйымдастырушылардың Excel файлын жүктеп, 12 білім беру бағдарламасының (БББ) қаржылық нәтижесін кейстің міндетті әдістемесі бойынша есептейді. Нәтижені дашбордта көрсетеді, ал жасанды интеллект сандарды түсіндіреді. Жауаптың әрқайсысында формула мен Excel жолы көрсетіледі.

> **Кратко (RU):** веб-приложение загружает выданный Excel, считает P&L 12 ОП строго по методике кейса (доход, ФОТ, прямые, накладные, результат, рентабельность, себестоимость на студента), находит 6 аномалий в «Сырые_сигналы», моделирует сценарий ±10% и прогноз набора. Суммы считает проверяемый код (`engine.js`, 48 автотестов против независимого эталона на Python), ИИ только интерпретирует результаты через вызовы инструментов и показывает источник и формулу.

## Іске қосу

**1-тәсіл: дайын демо.** [claude.ai артефактісі](https://claude.ai/artifact/NCXvcpxGjeuJduCF5tWAoV). Claude AI-талдаушысы тек осы жерде жұмыс істейді.

**2-тәсіл: өз компьютеріңізде.** Тек [Node.js](https://nodejs.org) 18+ керек, қосымша орнату қажет емес.

```bash
node tools/serve.js
```

Содан кейін браузерде `http://localhost:8765` ашыңыз. Тест файлы бетпен бірге автоматты түрде жүктеледі. Басқа файлды «Файл таңдау» батырмасымен немесе сүйреп әкеліп жүктеуге болады.

**Тесттер:**

```bash
node tests/engine.test.js
```

Эталонды қайта құру үшін (Python 3 және `openpyxl` керек):

```bash
python tests/make_reference.py data/Profitability_AI_Test_Data.xlsx
```

## Архитектура

```
Excel (.xlsx)
   │  SheetJS (браузерде, серверсіз)
   ▼
engine.js ── normalize()       құрылым, тип, сілтеме тексерісі; ақаулы жол есептен шығады
          ── compute()         кейс әдістемесі бойынша P&L (+ сценарий)
          ── detectAnomalies() «Сырые_сигналы» сапасы, P&L-ге кірмейді
          ── forecast()        сызықтық тренд + 80% болжам аралығы
          ── explainOp()       медианамен салыстырып факторлар мен нұсқалар
   │
   ▼
app.html ── дашборд, сүзгілер, БББ дәлелдері, сценарий, болжам
         ── AI-талдаушы:
              • Claude (claude.ai ішінде): list_programs, get_program, run_scenario,
                get_anomalies, get_forecast құралдарын шақырады. Сумманы өзі есептемейді.
              • Жергілікті талдаушы: Claude жоқ кезде сол ядроға сүйеніп жауап береді.
```

## AI моделі

- **Claude** (Anthropic) claude.ai артефактінің `sample` мүмкіндігі арқылы жұмыс істейді: «default» деңгейі және бет ішіндегі құралдар (tool use). Әр жауаптың астында қай құралдың шақырылғаны көрсетіледі.
- Модельге қойылатын ереже: санды тек құралдан алу, «Дәлел» бөлімінде формула мен Excel жолын көрсету, бағдарламаны тек қаржы бойынша жабуды ұсынбау.
- Claude қолжетімсіз болса, ережеге негізделген жергілікті талдаушы іске қосылады. Ол да кейстің мысал сұрақтарына (шығынды БББ, «неге», 1 студентке ФОТ, аномалиялар, ±10%, болжам) нақты сан мен дереккөз береді.

## 5 минуттық демо реті

1. **Жүктеу:** «Тест файлын ашу» батырмасын басу. «Тексеріс» бөлімінде 9/9 парақ, ФОТ ✓ және 500 000 000 ₸ ✓ көрінеді.
2. **Дашборд:** «Шығынды» сүзгісін қосу, содан кейін «Прикладная математика» жолын басу. Ашылған сарқырама диаграмма мен дәлелдер Excel жолдарымен бірге көрсетіледі.
3. **AI сұрағы:** «Неге „Прикладная математика“ нәтижесі осындай?» деп сұрау. Жауапта факторлар, нұсқалар және «Дәлел» бөлімі болады.
4. **Қате:** «Аномалиялар» бөлімінде 6 жол көрсетіледі, P&L-ге әсері 0 ₸.
5. **Сценарий:** бағдарлама таңдап, +10% басу. Басқа БББ-ның жанама шығыны қалай қайта бөлінгені және жалпы сома 500 000 000 ₸ ✓ болып қалғаны көрінеді.
