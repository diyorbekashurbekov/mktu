# Profitability AI

**Кейс 01 · University AI & Analytics.** Білім беру бағдарламаларының (ОП) рентабельділігін есептейтін, визуализациялайтын және түсіндіретін веб-қосымша. Ұйымдастырушы берген Excel файлын жүктейсіз → 12 ОП бойынша мөлдір P&L, дашборд, ИИ-талдаушы, «Сырые_сигналы» аномалиялары және «не болса?» сценарийлері.

> Барлық бағдарламалар, тарифтер, жалақылар мен сомалар — **синтетикалық**. Қосымша ЖСН-ді, студенттердің дербес деректерін немесе нақты жалақыларды жинамайды.

## Іске қосу

Python 3.10+ жеткілікті — **сыртқы пакеттер қажет емес** (Excel оқу да stdlib арқылы).

```bash
cd profitability-ai
python run.py
```

Браузер: <http://127.0.0.1:8010>. Іске қосылғанда `data/Profitability_AI_Test_Data.xlsx` демо файлы автоматты жүктеледі; басқа файлды «Excel жүктеу» батырмасымен немесе бетке сүйреп әкеліп жүктеуге болады.

Тесттер (35 тест: қаржылық дәлдік, жүктеу/валидация, аномалиялар, сценарий, ИИ, HTTP):

```bash
python -m unittest discover -s tests -v
```

### Claude қосу (міндетті емес)

Кілтсіз қосымша толық жұмыс істейді — ИИ-талдаушы офлайн, ережелік режимде. Claude-ты қосу үшін:

```bash
pip install -r requirements.txt
set ANTHROPIC_API_KEY=sk-ant-...      # PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."
python run.py
```

| Айнымалы | Әдепкі | Мағынасы |
| --- | --- | --- |
| `PORT` / `HOST` | `8010` / `127.0.0.1` | сервер мекенжайы |
| `PROFITAI_MODEL` | `claude-opus-5-5` | Claude моделі |
| `PROFITAI_EFFORT` | `low` | чатқа арналған effort деңгейі |
| `PROFITAI_LLM` | — | `off` — Claude-ты кілт болса да өшіру |

## Архитектура

```
Excel (.xlsx) ──► xlsx.py (zipfile + ElementTree, zip-bomb/XXE қорғанысы)
                    │
                    ▼
                loader.py  ── схема, типтер, тұтастық, кросс-тексерістер ──► issues[]
                    │
                    ├──► engine.py    міндетті әдістеме → P&L + әр сома үшін дереккөз жолдары
                    ├──► quality.py   Сырые_сигналы ережелері (P&L-ден оқшау)
                    ├──► scenario.py  ±Δ% контингент, жанаманы қайта бөлу, шығынсыздық
                    ├──► forecast.py  История_набора → болжам + белгісіздік
                    └──► insights.py  «Объяснить ОП»: факторлар + нұсқалар
                                │
                analyst.py — есептеу құралдары (tools) + офлайн intent-router
                llm.py     — Claude: құралды таңдайды, мәтінді құрастырады; сандар тексеріледі
                                │
                server.py (stdlib http.server, JSON API) ──► web/ (vanilla JS, SVG графиктер)
```

**API:** `GET /api/state` · `POST /api/upload` (дене = .xlsx байттары, `X-Filename`) · `POST /api/ask {question, op_id?}` · `GET /api/explain?op=OP-004&lang=kz|ru` · `POST /api/scenario {op_id, pct, fot_var, direct_var}` · `GET /api/export.csv` · `POST /api/reset`.

## ИИ моделі және мөлдірлік

- **Сомаларды LLM емес, код есептейді.** ИИ-талдаушының әр мүмкіндігі — `analyst.py` ішіндегі детерминирленген құрал (шығынды ОП тізімі, рейтинг, ОП түсіндіру, салыстыру, факультеттер, сценарий, аномалиялар, болжам, әдістеме).
- **Claude Opus 5.5** (`claude-opus-5-5`, ресми `anthropic` Python SDK) қосулы болса: сұрақты түсініп, керекті құралды tool use арқылы шақырады және жауапты сұрақ тілінде құрастырады. Мәтіндегі **әр сан құрал нәтижесімен салыстырылады**; тексерілмеген сан табылса, LLM жауабы алынып тасталып, детерминирленген жауап көрсетіледі (себебі «Дәлелдер» бөлімінде жазылады). Сервер жағындағы `fallbacks: "default"` (refusal кезінде) қосулы.
- **Кілт болмаса** — ережелік intent-router (қазақ/орыс тілі, ОП атауларының түрлі формалары, `OP-004` кодтары). Түсінбеген сұраққа сан ойлап шығармайды, сұрақ үлгілерін ұсынады.
- Этика: ОП-ны тек қаржылық нәтиже бойынша жабу ұсынылмайды — әр түсіндірмеде академиялық, кадрлық, стратегиялық және әлеуметтік негіздер туралы ескерту бар.

## Кратко по-русски

Веб-прототип для кейса «Profitability AI»: загрузка Excel без ручной правки, расчёт P&L по 12 ОП по обязательной методике (все приёмочные проверки проходят: ФОТ 736 465 200 ₸, накладные 500 000 000 ₸), дашборд с фильтрами, ИИ-аналитик (вопросы на русском и казахском; суммы считает код, Claude Opus 5.5 — опционально, с проверкой каждого числа), 6 аномалий в «Сырые_сигналы» без влияния на P&L, сценарий ±10% с перераспределением накладных, прогноз набора. Запуск: `python run.py`, без внешних зависимостей.
