Сұрақтарға дайын жауаптар:
- *ИИ сандарды ойлап шығармай ма?* — Барлық сомалар `engine.py`-да; LLM құрал шақырады; мәтіндегі әр сан құрал нәтижесімен салыстырылады, сәйкес келмесе — детерминирленген жауап.
- *Басқа файл жүктесе?* — Құрылым тексеріледі; міндетті парақ/баған жоқ болса — 422 және себеп тізімі, алдыңғы деректер сақталады; жеке жарамсыз жол шығарылып, ескерту беріледі.
- *Тесттер?* — `python -m unittest discover -s tests` — 35 тест, соның ішінде тәуелсіз эталондық есептеу.
