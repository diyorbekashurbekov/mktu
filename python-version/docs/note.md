# Profitability AI — қысқа жазба

Синтетикалық деректер · 2025–2026 оқу жылы · барлық сомалар теңгемен, бір жылға.

## 1. Формулалар (кейстің міндетті әдістемесі)

| Көрсеткіш | Формула | Дереккөз |
| --- | --- | --- |
| Кіріс ОП | Σ курстар (контракт_полный × тариф + контракт_со_скидкой × тариф × (1 − скидка_доля) + грант × финансирование_грант) | Контингент |
| Оқытушының жылдық ФОТ | зарплата_в_месяц × месяцев_оплаты × (1 + начисления_работодателя_доля) | Штат_ППС |
| ОП-ға ФОТ | Σ оқытушылар: жылдық ФОТ × ОП-дағы сағат / оқытушының барлық ОП бойынша сағаты | Штат_ППС, Нагрузка_ППС |
| Тікелей шығындар | Σ Прямые_затраты.сумма_в_год_тг (op_id бойынша) | Прямые_затраты |
| Жанама шығындар | Σ орталықтар: сомасы × ОП драйвері / 12 ОП драйверінің қосындысы (students ↔ студентов_активных, area_m2 ↔ площадь_м2, lab_hours ↔ лабораторные_часы) | Общие_затраты, Драйверы |
| Жалпы шығын | ФОТ + тікелей + жанама | — |
| Қаржылық нәтиже | кіріс − жалпы шығын | — |
| Рентабельділік | нәтиже / кіріс × 100% (кіріс = 0 → «н/д») | — |
| Бір студенттің құны | жалпы шығын / студентов_активных (0 → «н/д») | Драйверы |

Дөңгелектеу 2 таңбаға дейін тек экранда; есептеу мен CSV толық дәлдікпен.

## 2. «Объяснить ОП» — факторлар

Нәтиже дәл ыдыратылады:
`нәтиже = N × (ун-т нәтижесі/студент) + N·(кіріс/студ − орт.) − N·(ФОТ/студ − орт.) − N·(тікелей/студ − орт.) − N·(жанама/студ − орт.)`.
Факторлар теңгелік әсері бойынша сұрыпталады және драйверлермен түсіндіріледі (тариф, грант үлесі, жеңілдік, оқытушы сағаты/студент, сағат құны, аудан/студент, зертхана сағаты). Нұсқалар: шығынсыздыққа жеткізетін контингент (сценарий моделімен), шығынсыздық тарифі = (шығын − грант кірісі) / (толық + жеңілдікті × (1 − жеңілдік)), ағындарды біріктіру, ортақ зертханалар, реинвестиция — әрқайсысы тәуекелдерімен.

## 3. Сценарий болжамдары (базалық модель)

1. Таңдалған ОП-ның барлық курстарында толық ақылы, жеңілдікті және грант студенттері бірдей Δ%-ға өзгереді (құрылым сақталады).
2. Тариф, жеңілдік, грант қаржыландыруы өзгермейді → кіріс студенттер санына пропорционал.
3. ФОТ пен тікелей шығындар өзгермейді (кеңейтілген режимде айнымалы үлесті анық қоюға болады: шығын × (1 + Δ × үлес)).
4. Жанама орталықтардың жалпы сомасы (500 млн ₸) сақталады; students драйвері бар орталықтар жаңартылған студенттер саны бойынша қайта бөлінеді → басқа ОП-лардың нәтижесі де өзгереді.
5. area_m2 және lab_hours драйверлері тұрақты. Студенттер саны бөлшек болуы мүмкін (модельдік есеп).

## 4. Деректер сапасы

- Жүктеуде: міндетті парақтар/бағандар (жоқ болса — файл қабылданбайды, алдыңғы деректер қалады), сан/үлес типтері, теріс мәндер, белгісіз op_id / teacher_id, дубльдер, Контингент ↔ Драйверы сәйкестігі, жүктемесіз оқытушылар. Жарамсыз жол P&L-ден шығарылып, ескерту ретінде көрсетіледі.
- «Сырые_сигналы» — P&L-ге кірмейді. Ережелер: ID бірегейлігі, op_id ∈ ОП, applications ≥ 0, 0 ≤ conversion_pct ≤ 100, бос мән, кезең форматы және датасет жылдарына жатуы, белгісіз көрсеткіш. Түсініктеме бағаны анықтауда қолданылмайды (тест бар). Демо файлда 6 аномалия: SRC-004, SRC-901, SRC-902, SRC-903, SRC-904, SRC-905.

## 5. Шешімнің шекаралары

- Нәтиже кассалық қалдық емес; табыс салығы, инвестициялық бюджет, амортизация, кредиттер, зерттеулер, стипендиялар модельденбейді.
- Кіріс — есептелген (начисленный), нақты төлемдер емес; оқудан шығу, қарыздар ескерілмейді.
- Жанама шығынды бөлу ережесі — оқу моделі; нақты жүйеде оны қаржы-экономикалық қызмет бекітеді.
- Болжам 3 бақылауға негізделген — бағдарлау үшін ғана (интервал кең).
- ОП-ны жабу туралы шешім тек қаржылық нәтижеге сүйенбеуі тиіс.
- Прототип бір пайдаланушыға арналған (деректер жадта), аутентификация жоқ.

## 6. Нақты енгізу үшін қажет деректер

- Бухгалтериядан нақты кірістер (төлемдер, қарыздар, қайтарулар) және ай сайынғы контингент қозғалысы.
- ЖОО АЖ / Платонус: оқу жоспарлары, ағындар, нақты аудиториялық сағаттар.
- HR: ставкалар мен ФОТ агрегатталған түрде (дербес деректерсіз), қоса атқарушылық.
- Бекітілген жанама шығын бөлу әдістемесі, аудитория қоры, зертхана кестесі.
- Грант квоталары, нарықтық тарифтер, 5–7 жылдық қабылдау тарихы, демография.
- Енгізу: SSO, рөлдер (ректорат / факультет / қаржы), есеп кезеңдері, аудит журналы, деректердің жеке түрде сақталуы.
